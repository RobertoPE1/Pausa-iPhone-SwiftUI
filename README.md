# Pausa — aplicación final para iPhone

Proyecto base en SwiftUI para abrir en Xcode.

## Cómo usarlo

1. Crea en Xcode un proyecto nuevo: **iOS > App**.
2. Elige **SwiftUI** y sustituye los archivos generados por los archivos de la carpeta `Pausa`.
3. En `Assets.xcassets`, añade un icono propio basado en la hoja verde de la pantalla inicial.
4. Sustituye `Tu Nombre` por el nombre del alumno.

La aplicación contiene dos pantallas, navegación, transición nativa, temporizador y comentarios explicativos.
