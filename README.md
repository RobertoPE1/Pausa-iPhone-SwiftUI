# Pausa — aplicación final para iPhone

Proyecto SwiftUI preparado para abrir directamente en Xcode.

## Cómo usarlo

1. Abre `Pausa.xcodeproj` en Xcode.
2. Selecciona un simulador de iPhone y pulsa ▶️.
3. Sustituye `Tu Nombre` por el nombre del alumno.
4. Añade un icono propio en `Pausa/Assets.xcassets` antes de entregar.

La aplicación contiene dos pantallas, navegación, transición nativa, temporizador y comentarios explicativos.
